# Settled and Archived are one Archived section, and Archive settles the chat

> **One line changed by [ADR 0227](0227-new-bot-asks-only-for-a-name-the-bot-interviews-the-owner-in-its-bot-chat-and-one-card-sets-it-up.md)** (#85). "No action hides a chat in every Hermes client" has one exception: Set up again → Start fresh archives the bot's old Bot Chat in Hermes, so the next open makes a new one. That is `Hermes.archive`'s first caller. The row's Archive is unchanged.

> **Accepted.** It changes ADR 0090: the Settled drawer, the Settle and Unsettle actions and Settle all are now the Archived drawer, Archive, Unarchive and Archive all. It changes ADR 0201: the list's foot has one drawer, Archived, not Settled with Archived under it. It changes ADR 0005: no control hides a chat in every Hermes client, and only Unarchive still writes Hermes's archived flag, to clear it. The section model is `SECTION_KEYS` in `src/hermes/sectionKeys.ts` and `chatSections` in `src/hermes/snooze.ts`. Whether a chat is Archived, and what its Archive control does, is `inArchived` and `archiveAction` in `src/hermes/model.ts`. Unarchive is `setSettled` in `src/App.tsx`. Tested in `src/ui/chatSections.test.tsx`, `src/hermes/uiPrefs.test.ts` and `src/hermes/chatFilter.test.ts`.

The chat list had two places for chats out of the way, and two actions to put them there. Settle, the box icon, moved a chat into the Settled drawer. Archive, the eye-off icon, hid a chat in every Hermes client and moved it into the Archived drawer under Settled. Both took a chat out of the Inbox. The owner couldn't tell from the words when to use which, and the list's foot held two drawers that looked the same. They asked for one concept, named Archived: one row button, one drawer, and one word everywhere they read it. They also chose what it means. Archive does what Settle did.

## Decisions

- **Archive settles the chat.** The row's Archive button, the Archive item in its right-click menu and in the header's More menu do what Settle did. They set this app's attention flag (`Chat.settled`), which Hermes stores as its `pinned` flag turned off (ADR 0002). Archive works while a reply runs. Other Hermes clients still list the chat. Dragging a row onto the drawer, the Inbox header's Archive all, Undo, imported chats and pulled older history all work as they did, and only their words change. The code keeps the names `settled`, `onSettle` and `settleByDrop`, because they name the stored flag.
- **One Archived drawer holds every chat that is settled, archived in Hermes, or both.** It is the list's only drawer, at its foot, with the ten-then-Show-more paging of ADR 0185, newest first. A chat Hermes archived, from another Hermes client, is in it too. `inArchived` is the one test of whether a chat is Archived. The list's sections, the row's controls, the header's badge, the menus and Snooze all use it.
- **Archived outranks a pin.** A pinned chat the owner archives leaves Pinned for the drawer, and its pin comes back when it is unarchived. Before this, a settled chat that was also pinned stayed in Pinned, with an Unsettle button. That doesn't fit a button named Archive, so the row would have done nothing visible. Pin is not offered on an Archived chat, as it wasn't on one Hermes archived.
- **Unarchive brings a chat back to the Inbox.** It unsettles a settled chat, and restores a chat Hermes has archived (`Hermes.restore`). It does both when both hold. Hermes won't restore its archived chat while a reply runs, so such a chat has no Unarchive until the reply ends. Undo of an Unarchive settles the chat, which puts it back in the drawer without hiding it from other Hermes clients.
- **A drag never writes Hermes's archived flag.** A row dropped on the drawer is archived (settled), unless it is already Archived. A settled chat dropped on the Inbox is unarchived. A chat Hermes has archived, settled or not, stays where it is when dropped on the Inbox, since unsettling it alone would leave it in the drawer. Its Unarchive button restores it.
- **No action hides a chat in every Hermes client.** The row's eye-off button and the Archive and Restore items in the header's More menu go. `Hermes.archive` stays in the transport, unused by the app, so its tests keep covering the write path Unarchive shares.
- **One switch in Settings controls the drawer.** Settings → Chats → Chat list sections lists Pinned, Inbox, Snoozed, Working and Archived. As before, the Archived switch also decides whether the app lists the chats Hermes archived (`listArchived`). A stored list of shown or collapsed sections reads `settled` as `archived` (`uiPrefs.ts` `toSections`). So an owner who showed Settled and hid Archived still sees their settled chats, now with the chats Hermes archived beside them.
- **Search's state filter is Active or Archived.** Archived matches a chat settled here or archived in Hermes. With no state picked, search finds every chat, archived in Hermes or not, so the palette's "Search all chats, including Archived" holds. A filter saved with the state Settled reads as Archived, and one saved as All, archived too reads as no state.

## Considered options

- **Archive writes Hermes's archived flag.** Rejected. It hides the chat in every Hermes client, which the owner didn't ask for. Hermes refuses it while a reply streams, so the button would be missing on a busy chat. Every settled chat, imported transcript and pulled chat would also need a server write to show in the drawer.
- **Keep both concepts under new names.** Rejected. Two drawers and two buttons for chats out of the way was the problem, whatever they are called.
- **A pinned chat stays in Pinned when archived.** Rejected. Archive would then leave the chat where it was, with an Unarchive button and an Archived badge in the Pinned section.
- **Rename `settled` to `archived` in the code and on the server.** Rejected. Hermes's own archived flag already uses the name, and a rename moves no behavior.

## Consequences

- The list fetches the chats Hermes archived whenever Archived shows. Before this, an owner who showed Settled and hid Archived didn't fetch them. They now do, and can turn Archived off in Settings to stop it.
- Tests and the feature map find the drawer by `.archived-drawer` and its rows by `.archived-list`. `.sb-foot` has that one child. `.settled-drawer` and `.settled-list` no longer exist.
- A chat that is pinned on this computer and settled on Hermes, such as an old chat pulled in and then pinned, now shows in the drawer and not in Pinned.
- The verify stand-in gains `POST /__archive?id=<chat id>`, which archives a chat as another Hermes client would, so the feature map can drive a chat Hermes archived.
